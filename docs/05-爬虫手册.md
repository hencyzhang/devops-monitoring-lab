# Joybuy 爬虫手册

## 概述

使用 Playwright 连接 Chrome CDP 端口，从 joybuy.de 爬取商品分类和商品数据。joybuy.de 对服务器 IP 返回 403，必须在 Windows 真实浏览器中爬取。

## 前置条件

- Windows 系统，已安装 Chrome
- Python 3.11+
- Playwright: `pip install playwright`

## 第 1 步：启动 Chrome 调试端口

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\temp\chrome-debug"
```

保持 Chrome 窗口打开。

## 第 2 步：运行爬虫

双击 `scrape.bat`，或手动运行：

```powershell
python scrape_joybuy.py
```

## 工作流程

1. 通过 CDP 连接 Chrome (http://localhost:9222)
2. 打开 joybuy.de 首页
3. 自动发现分类链接（/minihome/ 路径）
4. 逐个分类抓取商品名称、价格、图片 URL
5. 写入 PostgreSQL 数据库 (db-node:5432, shop 库)

## 输出

- 每次运行约 1000+ 商品
- 表：products (name, category, price, image, stock)
- 每次爬取前自动清空旧数据

## 文件说明

| 文件 | 用途 |
|------|------|
| scrape_joybuy.py | 爬虫主脚本 |
| scrape.bat | 一键启动（自动开 Chrome + 运行脚本） |

## 注意事项

- joybuy.de 对 headless/自动化浏览器返回 403，必须用 CDP 连接真实 Chrome
- 必须在 Windows 上运行，不能在 Linux VM 上爬
- 商品图片使用 joy-sourcing.com 远程 URL
- 分类自动发现，不硬编码
